## Finding things quickly

- **In the repo:** use ripgrep, e.g. `rg -n "12 FPS" docs/` or search a command
  id like `rg -n "openMeshBoard"`.
- **In VS Code:** open the Command Palette and type **LabVIEW Benchmark Actor:**
  to see every command.
- **Metadata:** each page states its standard alignment and its related surfaces
  at the top, so you can navigate laterally without returning here.

# A single benchmark run + the frame it settled on

**Open Benchmark Run** shows one launch: the `launchMs` headline, the **UI-READY frame** the capture settled on (rendered as an 8×8 perceptual-fingerprint grid), and the capture stats.

**Open Benchmark Frame Correlator** is the interactive one: a **vertical-line scrubber**. Drag the slider (or use the arrow keys) to move through the runs — the upper graph shows each run's `launchMs`, and the lower pane shows the captured frame at that point. It correlates the *number* with the *picture*.
